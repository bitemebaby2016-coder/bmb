## 2. พฤติกรรมเช็คเอาท์ (แยกฟีเจอร์ชัดเจน)

- **สั่งวันนี้ (same-day):** ส่งวันนี้ทันที ระบบผูกกรอบจัดส่งให้เอง (ไม่ต้องเลือกกรอบ — แยกด้วยหมวด+วันอยู่แล้ว)
- **เมนูรอบพิเศษ (ตารางเมนู 7 วัน/14 เมนู):** วันจัดส่งถูกกำหนดโดยปฏิทินแอดมิน (ป้ายมุมเมนู) — หน้าเช็คเอาท์ **ล็อกวันอัตโนมัติ** (`resolveMenuBoundDate`) แสดง "วันจัดส่งถูกกำหนดโดยเมนูรอบพิเศษของแอดมิน" และ **ลูกค้าเลือกเฉพาะรอบจัดส่ง**
- **สินค้าทั่วไป (สินค้า same-day):** ติดไปกับรอบพรีออเดอร์ในออเดอร์เดียวและรับพร้อมกันที่รอบนั้น (เพิ่มในตะกร้าที่มีเมนูพรีออเดอร์แล้วส่งร่วมรอบเดียวกัน) · ถ้าไม่มีเมนูปฏิทินในตะกร้าเลย = **สั่งวันนี้เท่านั้น** (ไม่มีพรีออเดอร์วันอิสระ)
- **หลายวันเมนูในตะกร้าเดียว:** conflict แจ้ง "แยกสั่งคนละรอบ" (ไม่เดา/ไม่ merge — m1 ERR_DATE_CONFLICT)

## 5. รายการทดสอบโปรดักชั่น (สำหรับ Admin — ละเอียด)

> ก่อนเริ่ม: **ล้างแคช/รีเฟรชหน้าเว็บ (Ctrl+F5 หรือปิดเปิดแอปใหม่)** — build เก่าจะโชว์ป้ายวันผิด ("17 ต.ค.") และข้อความเตือนแบบเก่า

**A. พรีออเดอร์รับสินค้าทั่วไป (แก้เคสที่ทดสอบไม่ผ่าน)**
1. เพิ่มสินค้าธรรมดา (เช่น เนื้อเค็มชิ้นหมู, ชานมเผือก, เต้าหู้ปลานึ่งมะนาว) ลงตะกร้า → ไปหน้า Checkout → เลือก "สั่งล่วงหน้า (Pre-order)"
2. เลือกวันจัดส่ง (≥ พรุ่งนี้) + เลือกรอบ → กดยืนยันสั่งซื้อ
3. ✅ ต้องสำเร็จ **ไม่มี** toast "ไม่ใช่เมนูพรีออเดอร์/ไม่รองรับโหมด" — ได้ออเดอร์ PRE_ORDER 1 ออเดอร์
4. ลองตะกร้าผสม (เมนูพรีออเดอร์ + สินค้าธรรมดา) → ✅ สั่งได้ในรอบเดียวกัน (ออเดอร์เดียว)

**B. วันจัดส่งถูกกำหนดโดยปฏิทินแอดมิน (ลูกค้าเลือกแค่รอบ)**
5. แอดมิน: /admin/products → แท็บ "ตารางเมนูรอบพิเศษ" → เลือกวัน → เปิด 2 เมนู → Publish
6. ลูกค้า: เปิดเมนู → การ์ดเมนูที่อยู่ในตารางต้องมี "ป้ายปฏิทิน" วันที่กำหนด (มุมรูป)
7. เพิ่มเมนูนั้นลงตะกร้า → Checkout → ✅ ช่องวันที่ถูก **ล็อกเป็นวันจากป้าย** (disabled) + ข้อความ "วันจัดส่งถูกกำหนดโดยเมนูรอบพิเศษของแอดมิน" — เปลี่ยนวันเองไม่ได้ เลือกได้แค่ "รอบการจัดส่ง"
8. กดสั่ง → ✅ สำเร็จ และออเดอร์มีวันจัดส่งตรงกับปฏิทินเมนูเป๊ะ
9. ลองตะกร้าที่มีเมนู 2 วันต่างกัน → ✅ ขึ้นแดง "ถูกกำหนดวันจัดส่งต่างกัน … แยกสั่งคนละรอบ" และกดสั่งไม่ได้

**C. สินค้าเมนูผูกวัน/รอบ**
10. เลือกวันที่ **ไม่ใช่** วันเมนูของสินค้านั้น (แก้ในตะกร้า/ยิง API) → ✅ ถูกปฏิเสธ ERR_PRODUCT_NOT_ON_MENU
11. เมนูที่ผูก round key → เลือกอีกรอบ → ✅ ถูกปฏิเสธ; เลือกรอบที่กำหนด → ✅ ผ่าน

**D. Archive วันเมนูที่ผ่านรอบจัดส่ง**
12. ปล่อยเมนูค้างวันที่ผ่านไปแล้ว (เช่น เมื่อวาน) → ฝั่งลูกค้า: การ์ด/ปฏิทิน **ไม่โชว์** วันที่ผ่านไปแล้ว (ป้ายขึ้นเฉพาะวันถัดไป)
13. แอดมิน: week strip วันที่ผ่านไปแล้วขึ้น "📦" + tooltip "จัดเก็บแล้ว (ผ่านรอบจัดส่ง — วนใช้รอบถัดไปได้)" — กดดู/คัดลอกเมนูไปสัปดาห์ถัดไปได้

**E. Same-day (ของเดิมต้องไม่พัง)**
14. สั่งวันนี้ด้วยสินค้าธรรมดา → ✅ สำเร็จเหมือนเดิม (ระบบเลือกรอบอัตโนมัติ)
15. สินค้าที่ปิด "ส่งวันนี้" → สั่งวันนี้ → ✅ ยังถูกปฏิเสธ (ERR_PRODUCT_MODE_NOT_ALLOWED)

**F. แอดมินยุบรวมระลอก 2**
16. /admin → เมนู "เมนูและตารางเมนู" → ✅ มี 2 แท็บ (เมนู/สินค้า + ตารางเมนูรอบพิเศษ) สลับได้ + จำแท็บล่าสุด
17. เปิด /admin/menu-schedule ตรง → ✅ เด้งไป /admin/products?tab=schedule (bookmark เก่าไม่ตาย)
18. เมนู "องค์กรและแบรนด์" → ✅ 2 แท็บ (องค์กร/ร้านค้า + แบรนด์) · /admin/brands → ?tab=brands
19. รายการเมนูแอดมินไม่มี "ตารางเมนู"/"แบรนด์" ซ้ำแล้ว (ยุบเข้า hub)

**G. งานที่ server ทดสอบในโปรดักชั่นแล้ว (หลักฐาน: e2e/r5Apply141-*.json)**
