## 1. เริ่มต้นใช้งาน

### 1.1 เข้าสู่ระบบ
1. เปิดเว็บ `https://biteme-baby.com` แล้วกด **เข้าสู่ระบบ** (มุมขวาบน)
2. กรอกอีเมล + รหัสผ่านของบัญชีผู้ดูแล
3. เมื่อเข้าแล้ว แถบเมนูบนจะแสดงปุ่ม **Admin** — กดเพื่อเข้าหน้าจัดการ (`/admin`)

### 1.2 สิทธิ์การใช้งาน
- **เจ้าของร้าน (Owner)** เห็นทุกสาขา ทุกเมนู รวมถึง Tenants / Brands
- **ผู้ดูแลสาขา (Staff)** เห็นเฉพาะสาขาของตัวเอง — ข้อมูลทั้งหมด (ออเดอร์ เมนู รอบส่ง โซนส่ง) จะกรองตามสาขาอัตโนมัติ
- **สลับสาขา**: เลือกที่แถบ **Branch Switcher** ด้านบนของหน้าแอดมิน — ทุกตารางในหน้าจะเปลี่ยนตามสาขาที่เลือกทันที

### 1.3 หลักการทำงานสำคัญที่ควรรู้
- **ทุกอย่างบันทึกทันที** — กดปุ่มบันทึกแล้วลูกค้าเห็นผลทันที (บางหน้าใช้เวลาไม่เกิน 2-3 นาทีเพราะระบบแคชข้อมูลไว้)
- **ปุ่มเปิด-ปิด (Toggle)** ใช้แทนช่องทำเครื่องหมายแบบเดิมทั้งหมด — เขียว/ส้ม = เปิด, เทา = ปิด
- **ดรอปดาวน์ (Dropdown)** ใช้เลือกค่าจากตัวเลือกที่ระบบเตรียมไว้ — ไม่ต้องพิมพ์เอง
- ทุกการแก้ไขถูกบันทึกลง **ประวัติการทำงาน (Audit Log)** — ย้อนดูได้ว่าใครแก้อะไรเมื่อไร

## 2. 📊 แดชบอร์ด (Dashboard)

หน้าแรกหลังเข้าแอดมิน (`/admin`) — สรุปภาพรวมของ**สาขาที่เลือก**

- **ยอดขายวันนี้ / ออเดอร์วันนี้** — ตัวเลขสดจากออเดอร์จริง
- **ออเดอร์ล่าสุด** — กดที่รายการเพื่อไปหน้าออเดอร์
- **สถานะร้าน** — เปิด/ปิดรับออเดอร์ รอบส่งปัจจุบัน
- **ปุ่มลัด** — ไปหน้าที่ใช้บ่อย: ออเดอร์, เมนู, รอบส่ง, จัดส่ง

**เคล็ดลับ**: เริ่มต้นวันทำงานด้วยการเปิดแดชบอร์ดเพื่อเช็กจำนวนออเดอร์ค้างและสถานะรอบส่ง

## 3. 🎛 หน้าควบคุม (Control)

หน้ารวมสวิตช์ควบคุมระบบระดับสูง — ใช้เมื่อต้องการเปิด/ปิดความสามารถของระบบเฉพาะจุด (เช่น ช่องทางรับออเดอร์)

- ทุกปุ่มในหน้านี้เป็น **Toggle** — กดแล้วมีผลทันที
- **ข้อควรระวัง**: ปุ่มในหน้านี้กระทบการทำงานทั้งระบบ ถ้าไม่แน่ใจ อย่าเพิ่งกด — ถามผู้พัฒนาก่อน

---

## 4. 📦 ออเดอร์ (Orders)

### 4.1 ภาพรวมหน้า
- ตารางออเดอร์ทั้งหมดของสาขาที่เลือก เรียงจากใหม่ไปเก่า
- **ตัวกรองด้านบน**: สถานะออเดอร์ / โหมดสั่ง (สั่งวันนี้ / จองล่วงหน้า) / ช่วงวันที่ / ค้นหาด้วยเลขออเดอร์หรือเบอร์โทร
- กดที่แถวใดแถวหนึ่งเพื่อเปิด **รายละเอียดออเดอร์**

### 4.2 สถานะออเดอร์ที่ใช้ในระบบ
| สถานะ | ความหมาย |
|---|---|
| รอยืนยัน | ลูกค้าสั่งมาแล้ว รอร้านยืนยัน |
| ยืนยันแล้ว | รับออเดอร์แล้ว เตรียมของได้ |
| กำลังเตรียม | ครัวกำลังทำ |
| พร้อมส่ง | ทำเสร็จ รอไรเดอร์มารับ |
| กำลังส่ง | ไรเดอร์รับของแล้ว |
| ส่งสำเร็จ | ส่งถึงลูกค้าเรียบร้อย |
| ยกเลิก | ยกเลิกแล้ว (คืนเงินถ้าชำระแล้ว) |

### 4.3 ขั้นตอนจัดการออเดอร์
1. เปิดออเดอร์ที่ต้องการ
2. กด **ยืนยันรับออเดอร์** เมื่อรับทำ
3. เมื่อทำเสร็จ กด **ส่งเข้าครัว / ทำเสร็จ** ตามลำดับ
4. มอบหมายไรเดอร์ที่หน้า **จัดส่ง (Delivery)** — ดูขั้นตอนในบทที่ 20
5. เมื่อส่งสำเร็จ ระบบปิดวงจรอัตโนมัติ

### 4.4 การยกเลิก
- กด **ยกเลิกออเดอร์** แล้วเลือกเหตุผล — ระบบจดจำไว้ในประวัติ
- ออเดอร์ที่ชำระเงินแล้วจะเข้าคิว **คืนเงิน** ในหน้าการชำระเงิน (บทที่ 8)

---

## 5. 🍰 ครัว / การผลิต (Kitchen)

หน้าจอสำหรับทีมครัว — เห็นเฉพาะออเดอร์ที่ต้องทำตอนนี้

- **คิวงาน** — เรียงตามเวลาที่ต้องส่ง รายการไหนใกล้เวลาขึ้นก่อน
- กด **เริ่มทำ** / **ทำเสร็จ** เพื่อเลื่อนสถานะ
- แถบสีบอกความเร่งด่วน: แดง = ใกล้เวลาส่ง, เขียว = ทันเวลา

**เคล็ดลับ**: เปิดหน้านี้ทิ้งไว้บนแท็บเล็ตในครัว — จอจะอัปเดตเองเมื่อมีออเดอร์ใหม่

---

## 6. 🧪 สูตรอาหาร (Recipes/BOM)

กำหนดวัตถุดิบที่ใช้ต่อเมนู 1 จาน เพื่อให้ระบบหักสต็อกอัตโนมัติ

### ขั้นตอนเพิ่มสูตร
1. กด **+ เพิ่มสูตร**
2. เลือก **เมนู** จากดรอปดาวน์
3. เลือก **วัตถุดิบ** จากดรอปดาวน์ แล้วกรอก **ปริมาณที่ใช้** ต่อ 1 จาน
4. กด **บันทึก**

**ข้อควรระวัง**: ถ้าเมนูไหนไม่มีสูตร ระบบจะไม่หักสต็อกให้ — สินค้าประเภทของสด/ของมีจำนวนจำกัดควรตั้งสูตรให้ครบ

---

## 7. 🕐 รอบจัดส่ง (Rounds)

ตั้งเวลาส่งอาหารในแต่ละวัน — ลูกค้าจะเลือกรอบได้เฉพาะที่เปิดอยู่เท่านั้น

### 7.1 ขั้นตอนตั้งรอบส่ง
1. เปิดหน้า **Rounds** แล้วกด **+ เพิ่มรอบ**
2. กรอกข้อมูล:
   - **ชื่อรอบ** — เช่น รอบเช้า, รอบกลางวัน, รอบเย็น
   - **เวลาตัดรอบ (Cutoff)** — เวลาที่ปิดรับออเดอร์ของรอบนั้น เช่น 08:00
   - **ช่วงเวลาส่ง** — เช่น 06:00–09:00
   - **จำนวนรับได้สูงสุด** — จำกัดจำนวนออเดอร์ต่อรอบ
3. เลือก **สาขา** ในดรอปดาวน์
4. กด **บันทึก**

### 7.2 ปุ่มเปิด-ปิดรอบ
- ปุ่มท้ายแต่ละแถว = **เปิด/ปิดรับออเดอร์** ของรอบนั้น — ปิดแล้วลูกค้าเลือกรอบนั้นไม่ได้

### 7.3 ข้อควรระวัง
- **ตั้งรอบให้ครบวันนี้ + พรุ่งนี้เสมอ** — ลูกค้าจะเห็นตัวเลือกสั่งถูกต้อง
- ระบบปิดรับอัตโนมัติตามเวลาตัดรอบ — ไม่ต้องนั่งเฝ้า
- ถ้ารอบไหนเต็ม (ถึงจำนวนสูงสุด) ระบบจะปิดรับรอบนั้นเอง

---

## 8. 💳 การชำระเงิน (Payments)

จัดการเรื่องเงิน — ชำระแล้ว/ยังไม่ชำระ/ค้างคืนเงิน

- **ตารางการชำระเงิน** — เห็นสถานะของทุกออเดอร์ที่มีการชำระเงิน
- **หน้าข้อยกเว้น (Payment Exceptions)** — ออเดอร์ที่มีปัญหา เช่น จ่ายเงินแล้วแต่ระบบไม่รับรู้, ค้างคืนเงิน
  - กดที่รายการ → เลือก **ยืนยันว่ารับเงินแล้ว** หรือ **คืนเงิน**
  - ทุกการแก้ไขถูกบันทึกในประวัติการทำงาน

**ข้อควรระวัง**: การคืนเงินผ่านบัตรเครดิตใช้เวลา 5-10 วันทำการ — เงินสด/โอน คืนได้ทันที

## 9. 🍽️ จัดการเมนู (Menu)

หน้าที่ใช้บ่อยที่สุด (`/admin/products`) — จัดการเมนู หมวดหมู่ กลุ่มเมนู และเมนูยอดนิยม

### 9.1 เพิ่ม/แก้ไขเมนู
1. กด **+ เพิ่มเมนู**
2. กรอกข้อมูล:
   - **ชื่อเมนู** — ชื่อที่ลูกค้าเห็น
   - **ราคา (บาท)**
   - **หมวดรอง (หมวดหมู่)** — เลือกจากดรอปดาวน์
   - **เวลาเตรียม (นาที)** — ระบบใช้คำนวณเวลาส่ง
   - **รายละเอียด** — คำอธิบายสั้น ๆ ใต้ชื่อเมนู
   - **รูปเมนู** — อัปโหลดจากเครื่องหรือถ่ายรูปใหม่ หรือวางลิงก์รูปก็ได้
3. ตั้งสวิตช์:
   - **เปิดขาย** (Toggle) — ปิด = ซ่อนจากลูกค้าชั่วคราว
   - **แนะนำ** (Toggle) — เปิด = ขึ้นป้ายแนะนำ
   - **วิธีขาย** (Dropdown) — "สั่งได้วันนี้ — ส่งวันนี้" หรือ "จองล่วงหน้า — เลือกวันจัดส่ง"
4. กด **บันทึก**

### 9.2 หมวดรอง (หมวดหมู่ / Category)
- **+ เพิ่มหมวดหมู่** — ตั้งชื่อ, ไอคอน (อิโมจิ), ลำดับการแสดง, **หมวดหลัก (กลุ่มเมนู)** (ดรอปดาวน์), ปุ่มเปิด-ปิด **แสดงหมวดนี้**
- ปุ่มแก้ไข/ลบ/กู้คืนท้ายแต่ละแถว — ลบแล้วกู้คืนได้
- หมวดหมู่ที่ปิด = ซ่อนจากลูกค้าทันที
- **หมวดว่าง (ยังไม่มีเมนูพร้อมขาย) = ซ่อนอัตโนมัติ** ทั้งหน้าแรกและหน้าเมนู (ไม่โชว์การ์ดเปล่า)
- ป้ายชื่อในฟอร์มเมนู/หัวข้อการ์ดใช้ชื่อ **"หมวดรอง (หมวดหมู่)"** — ให้ตรงกับโครงสองชั้นด้านล่าง

### 9.3 หมวดหลัก (กลุ่มเมนู / Section)
- กลุ่มใหญ่ที่ครอบหลายหมวดหมู่ เช่น "อาหารจานเดียว", "เครื่องดื่ม"
- **+ Section** → ตั้งชื่อ + ลำดับ → บันทึก
- จัดหมวดหมู่เข้ากลุ่มโดยเลือก "หมวดหลัก (กลุ่มเมนู)" ในฟอร์มหมวดหมู่
- **โครงสองชั้นที่ลูกค้าเห็น (เหมือนกันทั้งหน้าแรก /shop และหน้าเมนู /menu):**
  **หมวดหลัก (Section) → หมวดรอง (หมวดหมู่) → การ์ดเมนู** — ปุ่มกรองหมวดก็จัดกลุ่มตามหมวดหลักด้วย
- หมวดรองที่อยู่ในหมวดหลักซึ่งปิดอยู่ = ซ่อนทั้งหมวด (ตรงกับระบบฝั่งเซิร์ฟเวอร์)

### 9.4 🔥 เมนูยอดนิยม (หน้าแรก)
แผงสำคัญ — ควบคุมช่องโชว์เมนูพิเศษบนหน้าแรกของลูกค้า (**ช่องเดียวจบ** — ช่อง "เมนูวันนี้" เดิมถูกรวมเข้าช่องนี้แล้ว ไม่มีช่องซ้ำ)

**ขั้นตอนตั้งค่า:**
1. แผง "🔥 เมนูยอดนิยม (หน้าแรก)" → ใช้ **ดรอปดาวน์เลือกเมนู** (จัดกลุ่มตามกลุ่มเมนู/หมวดหมู่ รวมเมนูจองล่วงหน้า) แล้วกด **+ เพิ่ม**
2. จัดการรายการที่เลือก:
   - **thumbnail + ปุ่ม "เปลี่ยนรูป"** ท้ายแถว = เปลี่ยนรูปเมนูได้ทันทีจากแผงนี้ (อัปโหลดแล้วบันทึกลงเมนูอัตโนมัติ — รูปใหม่ขึ้นหน้าเว็บทันที)
   - **ปุ่มเปิด-ปิด** ท้ายแถว = โชว์/ซ่อนเมนูนั้นชั่วคราว (ไม่ต้องลบออกจากรายการ)
   - **↑ / ↓** = จัดลำดับการแสดง
   - **เอาออก** = ลบเมนูจากรายการ
3. ตั้งค่าเพิ่มเติม:
   - **หัวข้อช่อง** — ชื่อที่แสดงบนหน้าแรก (ค่าเริ่มต้น "เมนูยอดนิยม")
   - **จำนวนที่โชว์ต่อรอบ** (Dropdown) — 4/6/8/10/12/16 เมนู
   - **สลับสับเปลี่ยนเมนูอัตโนมัติ** (Toggle) — ระบบหมุนเวียนรายการทุก 30 นาที
4. กด **💾 บันทึก** — ลูกค้าเห็นผลทันที

**ถ้ายังไม่ได้เลือกเมนูใดเลย** ระบบจะสลับเมนูแนะนำจากทุกกลุ่มมาโชว์ให้อัตโนมัติ

**ป้ายปฏิทินมุมรูปเมนูจองล่วงหน้า** — แสดง "วัน-เดือน" ที่หัวมุมรูป แตะ/ชี้เพื่อดูปฏิทินเดือนนั้น (วันจัดส่งไฮไลต์):
- วันที่แสดง **มาจาก "ตารางเมนู" (บท 10) เท่านั้น** — แก้วันที่วันไหน ลูกค้าเห็นวันนั้น
- ไม่มีตารางเผยแพร่ของเมนูนั้น = ไม่แสดงป้ายวันที่ (ไม่โชว์วันเก่า)

### 9.5 ข้อความบนหน้า (แก้ได้ในแผงเดียวกัน)
- **หัวข้อช่องจองล่วงหน้า** — ข้อความช่องจองล่วงหน้าบนหน้าแรก
- **ข้อความเตือนใต้แคมเปญ** — ข้อความเล็กใต้ป้ายโปรโมชั่นลอย

## 10. 📅 ตารางเมนู (Menu Schedule)

กำหนดว่าเมนูไหนขายวันไหน — เหมาะกับร้านที่หมุนเวียนเมนูตามวัน

1. เลือก **วันที่** ที่ต้องการ
2. ติ๊กเมนูที่จะเปิดขายในวันนั้น
3. กด **บันทึก** → ลูกค้าเห็นเฉพาะเมนูที่เปิดขายในวันนั้น

**ปฏิทินมุมรูปการ์ดเชื่อมกับตารางนี้โดยตรง:** วันที่โชว์บนป้ายมุมรูปเมนูจองล่วงหน้า (ทุกหน้า — หน้าแรก/หน้าเมนู) คือ **วันจัดส่งถัดไปที่เผยแพร่ในตารางนี้** — แก้ที่นี่แล้วป้ายเปลี่ยนทันที ไม่ต้องแก้ไขเมนูทีละตัว และไม่มีทางโชว์วันผิดจากค่าเก่าในตัวเมนู

**เคล็ดลับ**: ใช้คู่กับ "วิธีขาย = จองล่วงหน้า" เพื่อเปิดรับออเดอร์ล่วงหน้าสำหรับเมนูพิเศษเฉพาะวัน

## 11. 🎁 โปรโมชั่น (Promotions)

### 11.1 สร้างโปรโมชั่น

### 11.2 ป้ายโปรโมชั่นลอย (Floating Banner)
- เปิดสวิตช์ **แสดงเป็นป้ายลอย** — ป้ายจะเด้งขึ้นกลางจอลูกค้าพร้อมข้อความเตือนด้านล่าง
- ลูกค้ากด ✕ ปิดได้ — ปิดแล้วจะไม่เด้งซ้ำในรอบการใช้งานนั้น
- **ข้อความเตือนใต้ป้าย** แก้ได้ในแผงเมนูยอดนิยม (บท 9.5)

## 20. 🚗 จัดส่ง (Delivery)

หน้าจัดการไรเดอร์และการส่งของ — รวมขั้นตอนเพิ่ม/ผูกบัญชีไรเดอร์

### 20.1 เพิ่มไรเดอร์ใหม่
1. แผง **"เพิ่ม/จัดการไรเดอร์"** → กรอก **ชื่อไรเดอร์** + **เบอร์โทร** (+ รายละเอียดรถ ถ้ามี)
2. กด **➕ เพิ่มที่ไรเดอร์**
3. ระบบจะ **กำหนดสาขาให้อัตโนมัติ** (ใช้สาขาหลักของร้าน) — ไม่ต้องเลือกเอง
4. ✅ เสร็จ — เบอร์ซ้ำ = อัปเดตข้อมูลไรเดอร์เดิม ไม่สร้างซ้ำ

### 20.2 ผูกบัญชีเข้าสู่ระบบให้ไรเดอร์
> ต้องสร้างบัญชีผู้ใช้ก่อน (เจ้าของร้านสร้างในระบบ Supabase) แล้วจึงผูก:
1. แผงเดียวกัน → เลือก **บัญชีผู้ใช้** ในดรอปดาวน์ท้ายแถวไรเดอร์
2. กด **🔗 ผูกบัญชี**
3. ✅ ไรเดอร์เข้าสู่ระบบที่ `/rider` ด้วยบัญชีนั้นได้ทันที

### 20.3 มอบหมายงานส่ง
1. ส่วน **คิว Dispatch — พร้อมส่ง** จะแสดงออเดอร์ที่ทำเสร็จแล้ว
2. เลือก **ไรเดอร์** ในดรอปดาวน์ท้ายออเดอร์ → กด **มอบหมาย**
3. ไรเดอร์เห็นงานในแอปทันที

### 20.4 ติดตาม/ปิดงาน
- **สถานะไรเดอร์** — เห็นว่าใครว่าง/กำลังส่ง
- **เดินหน้าสถานะ** — เลื่อนสถานะงานส่งจนจบ (ใช้เมื่อต้องปิดงานแทนไรเดอร์)
- ปุ่ม **ปิดวงจร** — ปิดงานค้างทั้งหมดในครั้งเดียว

### 20.5 ข้อความแจ้งเตือนในหน้านี้
ข้อความผิดพลาดทั้งหมดแสดงเป็นภาษาไทย เช่น "กรอกข้อมูลไม่ครบ — ต้องมีชื่อและเบอร์โทร", "ออเดอร์นี้ยังไม่อยู่ในสถานะพร้อมส่ง" — ถ้าเห็นข้อความแจ้งปัญหาเรื่องสาขา ให้ตั้งค่าสาขาในหน้า Settings ก่อน

## 25. ⚙️ ตั้งค่า (Settings)

**สำคัญ**: ตั้งเวลาเปิด-ปิดให้ถูกต้อง — มีผลต่อสถานะร้านบนหน้าเว็บและมาสคอตของลูกค้า

## 28. แก้ปัญหาที่พบบ่อย (FAQ)

**Q1: เพิ่มไรเดอร์แล้วขึ้นข้อความผิดพลาดเรื่องสาขา?**
A: ระบบจะกำหนดสาขาให้อัตโนมัติแล้ว — ถ้ายังเจอปัญหา ให้ไปตั้งค่าสาขาที่หน้า Settings ให้เรียบร้อยก่อน แล้วลองใหม่

**Q2: แก้เมนู/ราคาแล้ว แต่หน้าเว็บลูกค้ายังเป็นค่าเก่า?**
A: รอ 2-3 นาทีแล้วรีเฟรชหน้า — ระบบเก็บข้อมูลชั่วคราวเพื่อความเร็ว ถ้ายังไม่เปลี่ยน ลองปิด-เปิดแอปมือถือใหม่

**Q3: ลูกค้าบอกว่าเห็น "ร้านปิด" ทั้งที่ร้านเปิดอยู่?**
A: ตรวจ **เวลาเปิด-ปิดร้าน** ในหน้า Settings และตรวจ **รอบจัดส่ง (Rounds)** ว่ามีรอบเปิดรับอยู่ไหม — ระบบใช้สองอย่างนี้ร่วมกัน

**Q4: อยากให้มาสคอตกลับเป็นท่าปกติ แต่ช่วงร้านปิดมันเปลี่ยนเป็นท่าเศร้า?**
A: นี่คือพฤติกรรมตั้งใจไว้ — ช่วงร้านปิดมาสคอตจะใช้ท่าเศร้า/ปิดร้านอัตโนมัติทุกจุด ไม่ต้องแก้ไขอะไร

**Q5: โปรโมชั่นลอยไม่เด้งให้ลูกค้าเห็น?**
A: ตรวจว่าเปิดสวิตช์ "แสดงเป็นป้ายลอย" แล้ว และโปรโมชั่นยังเปิดใช้งานอยู่ — ลูกค้าที่กดปิดไปแล้วจะไม่เห็นซ้ำในรอบการใช้งานนั้น (เปิดหน้าใหม่จะเห็นอีกครั้ง)

**Q6: มอบหมายงานให้ไรเดอร์ไม่ได้?**
A: ตรวจว่าออเดอร์อยู่ในสถานะ "พร้อมส่ง" ก่อน — ถ้ายังไม่พร้อม ต้องเลื่อนสถานะออเดอร์ให้ถึงขั้นพร้อมส่งก่อน

**Q7: อยากเปลี่ยนสีธีมเว็บ?**
A: กดปุ่ม **สลับธีม** (ไอคอนพระอาทิตย์/พระจันทร์ มุมขวาบนของหน้าเว็บ) — มี 3 ธีม: สว่าง, มืด, น้ำเงินลึก ลูกค้าเลือกใช้ได้อิสระ

**Q8: ต้องการเพิ่มเมนู "จองล่วงหน้า" ทำอย่างไร?**
A: ในหน้าเมนู (บท 9.1) ตั้ง **วิธีขาย = จองล่วงหน้า — เลือกวันจัดส่ง** แล้วตั้งวันที่พร้อมส่งในข้อมูลเมนู — ลูกค้าจะเห็นปุ่มจองล่วงหน้าพร้อมปฏิทินวันส่งบนหน้าเมนู
