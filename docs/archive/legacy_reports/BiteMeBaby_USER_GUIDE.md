## วิธีสั่งซื้ออาหาร

1. เปิดเว็บ: **https://bitemebaby-5f7.pages.dev**
2. เลือกเมนูที่ต้องการ --> กดปุ่ม **สั่งทันที** (same-day) หรือ **จองล่วงหน้า** (pre-order)
3. เพิ่มลงตะกร้า --> ไปหน้า **Checkout**
4. เลือกช่วงเวลาส่งอาหาร (delivery round), กรอกที่อยู่, เลือกวิธีชำระเงิน (PromptPay / บัตร / เงินสด COD)
5. ได้รับหมายเลขคำสั่งซื้อ (BMB-YYYYMMDD-XXX) และติดตามสถานะได้

## วิธีการชำระเงิน

| วิธี | รายละเอียด |
|------|------------|
| PromptPay | สแกน QRCode บนหน้าจอ --> โอนเงิน |
| บัตรเครดิต | ใช้ Stripe --> กรอกข้อมูลบัตร |
| เงินสด (COD) | จ่ายให้พนักงานเมื่อรับสินค้า |

ราคาทั้งหมดคำนวณฝั่ง server (server-authoritative) --> ไม่เปลี่ยนแปลงหลังยืนยัน

## การติดตามสถานะออเดอร์

- สถานะ: pending --> confirmed --> preparing --> ready_for_dispatch --> dispatched --> in_transit --> delivered
- เส้นทาง `/track/<หมายเลข>` --> ดูสถานะแบบ real-time

---

## AI-Assistant (Bite)

- ไอคอนแชทลอยตัวทุกหน้า
- ถามเกี่ยวกับเมนู, โปรโมชั่น หรือสถานะออเดอร์

## โปรโมชันและรางวัล

- รหัสส่วนลดในตะกร้า
- คะแนนสะสมจากการสั่ง --> แลกของรางวัล (Rewards)
