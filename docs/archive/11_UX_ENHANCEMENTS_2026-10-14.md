## คู่มือแอดมิน — "เมนูยอดนิยม" และข้อความหน้าเว็บ

ไปที่ **หน้าจัดการเมนู (`/admin/products`)** → แผง **"🔥 เมนูยอดนิยม (หน้าแรก)"**

1. **เลือกเมนู** — ใช้ดรอปดาวน์ "เลือกเมนูเพื่อเพิ่ม" (จัดกลุ่มตามกลุ่มเมนู/หมวดหมู่ รวมเมนูจองล่วงหน้า) แล้วกด "+ เพิ่ม"
2. **ปุ่มเปิด-ปิด** ท้ายแต่ละแถว = โชว์/ซ่อนเมนูนั้นชั่วคราว (ไม่ต้องลบออกจากรายการ)
3. **↑ / ↓** จัดลำดับ, **เอาออก** ลบเมนูจากรายการ
4. **สลับสับเปลี่ยนเมนูอัตโนมัติ** (ปุ่มเปิด-ปิด) — ระบบหมุนเวียนรายการทุก ~30 นาที; ปิด = โชว์ตามลำดับที่จัด
5. **หัวข้อช่อง** — เปลี่ยนชื่อช่องแรกได้ (ค่าเริ่มต้น "เมนูยอดนิยม")
6. **ข้อความเตือนใต้แคมเปญ / หัวข้อช่องจองล่วงหน้า** — แก้ได้ในแผงเดียวกัน
7. กด **💾 บันทึก** → ลูกค้าเห็นผลทันที ไม่ต้อง deploy (ค่าเก็บตาราง `business_settings`)

ถ้ายังไม่ได้เลือกเมนูใดเลย ระบบจะคละเมนูแนะนำจากทุกกลุ่ม (สั่งวันนี้ + จองล่วงหน้า) มาโชว์ให้อัตโนมัติ

## หมายเหตุสำหรับผู้พัฒนา

- ระบบ "เมนูยอดนิยม": `src/lib/homePopular.ts` (logic ล้วน + default ทั้งหมดอยู่ในไฟล์เดียว — แก้ copy เริ่มต้นได้ที่นี่)
- การ์ดใหม่ในอนาคต: ใช้คลาส `.menu-card` + `.menu-card-media` จะได้ hover รูปลอยเหนือกรอบ + ปฏิทินลอยอัตโนมัติ
  (การ์ดเดิม `.drink-card` / `.snack-card` / `.home-card` / `.fmc-card` ผูกไว้ให้แล้วใน `src/index.css`)
- ป้ายวันจัดส่ง: `<ScheduleDateBadge date="YYYY-MM-DD" />` วางในพื้นที่รูป (container ต้อง `position: relative`)
- ปุ่มเปิด-ปิดแอดมิน: `<ToggleSwitch checked onChange label testId />` ที่ `src/components/admin/ToggleSwitch.tsx`
- ข้อความ default ของหน้าเว็บอยู่ที่ `DEFAULT_SITE_COPY` / `DEFAULT_HOME_POPULAR` ใน `src/lib/homePopular.ts`
