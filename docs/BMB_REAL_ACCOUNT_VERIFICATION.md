## 1. Guest Checkout (P2)

**ขั้นตอน:**
1. เปิด **หน้าต่าง/เบราว์เซอร์ใหม่ที่ไม่มี session** (Incognito) → เพิ่มสินค้าลงตะกร้า
2. ไป `/checkout` → ต้องเห็น **กล่อง "ยืนยันเบอร์โทรศัพท์"** (ไม่ใช่หน้า redirect ไป login)
3. กรอกชื่อ + เบอร์จริง → กด **"ส่งรหัสยืนยัน"**
4. รับรหัส 6 หลักทาง SMS → กรอก → กด **"ยืนยันและสั่งซื้อต่อ"**
5. ต้องเข้าสู่ฟอร์มสั่งซื้อต่อได้ทันที (ไม่ต้องสมัครสมาชิก)

**เกณฑ์ผ่าน:**

| # | ต้องเจอ |
|---|---|
| 1 | กล่องยืนยันเบอร์ขึ้นแทนการ redirect |
| 2 | รหัส SMS ใช้ได้จริง · รหัสเก่าใช้ซ้ำไม่ได้ |
| 3 | สั่งซื้อต่อได้โดยไม่ต้องตั้งรหัสผ่าน |
| 4 | กลับมาครั้งหน้า (เบอร์เดิม) → เจอข้อมูล/ประวัติเดิม |
| 5 | **รหัสผิด/หมดอายุ → ต้อง "ไม่มีออเดอร์" เกิดค้าง** |

## 2. Facebook Login (P3) — บัญชีจริง

**ขั้นตอน:**
1. เข้า `/login` → ปุ่ม **"เข้าสู่ระบบด้วย Facebook"**
2. ใช้ **บัญชี Facebook จริงที่มี Role ใน App** ล็อกอิน
3. ยอมรับสิทธิ์ → ต้องถูกพากลับมาที่หน้าที่มาก่อน (เช่น `/checkout`)
4. ตรวจว่าได้ session จริง (เมนูเปลี่ยนเป็นสถานะล็อกอิน)

**เกณฑ์ผ่าน:**

| # | ต้องเจอ |
|---|---|
| 1 | OAuth พาไป Facebook จริง แล้วกลับมาหน้าเดิม |
| 2 | กด **"ยกเลิก"** ที่หน้า Facebook → ต้องขึ้นข้อความไทย "คุณยกเลิกการอนุญาต Facebook" ไม่ใช่หน้าขาว |
| 3 | **Facebook เข้าถึงบัญชี Quick Login/Guest Checkout ไม่ได้** — บัญชีพวกนั้นใช้ `<phone>@phone.bmb.local` ซึ่ง Facebook คืนมาไม่ได้ |
| 4 | ถ้าอีเมลจาก Facebook มีเจ้าของอยู่แล้ว → ต้องถูกบอกให้เข้าสู่ระบบด้วยวิธีเดิม **ไม่ถูก merge อัตโนมัติ** |

**Negative test (สำคัญ):** ใช้ Facebook บัญชีที่อีเมลซ้ำกับบัญชีอีเมล/รหัสผ่านเดิม → ต้อง **ไม่ได้สิทธิ์เพิ่ม** และไม่มีบัญชีถูกผูกอัตโนมัติ

## 3. Passkeys (P4)

**ขั้นตอน:**
1. ล็อกอินด้วยวิธีอื่นก่อน (Facebook / Quick Login / Guest)
2. ไป `/profile` → ปุ่ม **"+ สร้าง Passkey"** → ยืนยัน Face / Touch ID / ล็อกหน้าจอ
3. **ออกจากระบบ**
4. กลับ `/login` → ปุ่ม **"เข้าสู่ระบบด้วย Passkey"**
5. ยืนยันตัวตน → ต้องเข้าได้โดยไม่ต้องพิมพ์อะไร

**เกณฑ์ผ่าน:**

| # | ต้องเจอ |
|---|---|
| 1 | ปุ่ม Passkey **ไม่ขึ้นเลย** ถ้าเบราว์เซอร์/เครื่องไม่รองรับ |
| 2 | สร้าง Passkey ได้จริง + ขึ้นในรายการที่ `/profile` |
| 3 | Sign-in ด้วย Passkey ได้จริง |
| 4 | ยกเลิกตอนยืนยัน → ข้อความไทย "คุณยกเลิกการยืนยันตัวตน" (ต่างจาก challenge หมดอายุ) |
| 5 | ลบ Passkey ที่ `/profile` แล้ว ปุ่ม sign-in ต้องใช้ไม่ได้ + บอกให้ใช้วิธีอื่น |
| 6 | **สมัครต้องมี session** → บุคคลภายนอกไม่มีทางผูก passkey เข้าบัญชีคนอื่น |

## 4. บันทึกผล (สำคัญ — ห้ามข้าม)

ทุกครั้งที่ทดสอบ ให้จด **อย่างน้อย** 4 อย่างนี้:

1. **อุปกรณ์ + เวอร์ชัน** (เช่น iPhone 13 / iOS 17.5, Chrome 130)
2. **เวลา UTC** ที่ทดสอบ
3. **ผลจริง** — ไม่ใช่ "น่าจะผ่าน"
4. **ภาพหน้าจอ** ถ้าเจอสิ่งผิดปกติ

> ถ้าข้อไหนยังไม่ได้ทดสอบจริง → ให้เขียน **"ยังไม่ได้ทดสอบ"**
> **ห้าม** เขียนว่า "ผ่าน" โดยอ้าง unit test หรือ CI
