## B. 4 บั๊กที่ท่านเห็นจากหน้าจอ — แก้ตรงไหน ยังไง

### B1 หัวข้อเมนูซ้ำ + เรียงไม่ตรง (แก้ที่ `src`)
**สาเหตุจริง:** แถวแท็บหน้าแรก/หน้าเมนูมี "แท็บโหมด" (🛵 ส่งวันนี้ / 📅 พรีออเดอร์ · /menu: 🍽️ วันนี้ / 📅 จองล่วงหน้า)
**และ** ปุ่มหมวด "ส่งวันนี้ / Same Day" · "จองล่วงหน้า / พรีออเดอร์" จากฐานข้อมูล → แสดง 2 ที่ = "มันคืออันเดียวกัน"
ตามที่ท่านยืนยัน · ส่วน "เรียงหัวข้อใหม่ไม่เคยโดน" เพราะโค้ดเทียบ **ชื่อตรงตัว** กับลิสต์ pinned
ที่ชื่อไม่ตรง DB จริง (ของทานเล่น vs ของหวานลัน · สินค้าสำเร็จรูป vs เมนู_สำเร็จ)
**แก้แล้ว:**
- `catalogStructure.ts` — `CATEGORY_DISPLAY_ORDER` เป็นลิสต์ **alias** (ความหมายเดียวกัน = อันดับเดียวกัน):
  1 เมนูสุขภาพ → 2 เครื่องดื่ม → 3 ของทานเล่น/ผลไม้ **(= ของหวานลัน/ผลไม้)** → 4 สินค้า_for **(= เมนู_สำเร็จ)**
  → 5 ส่งวันนี้/Same Day → 6 จองล่วงหน้า/พรีออเดอร์ → หมวดอื่นตาม sort_order ของแอดมิน
- `HomePage` + `MenuPage` — **แถว chips ไม่โชว์หมวดโหมดซ้ำ** (แท็บโหมดรับผิดชอบแทน · deep-link `?category=` ยังใช้ได้)
- `CategorySections` (หน้าแรก) — ไม่สร้างหัวข้อหมวดโหมดซ้ำ · **สินค้าของหมวดนั้นถูกย้ายเข้าเซกชัน
  🛵 ส่งวันนี้ / 📅 พรีออเดอร์** โดยจัดหมวดตัวเองมาก่อนตัด 8 ชิ้น → ไม่มีเมนูหาย
- ที่หน้า /menu: หัวข้อหมวดยังอยู่ครบ (ไม่มีเซกชันโหมดซ้อน) · เหลือแท็บ + chips + เรียงตาม alias ใหม่
**เทสต์:** homeMenuAdminOrdering(9) · categorySections(6 · มีเคส alias ใหม่) · homeSectionModeCta(14 · 2 เคส
เปลี่ยนเป็น "ไม่สร้างหัวข้อซ้ำ") · preOrderEntry(10) — ทั้งหมดเขียว

### B2 กรอบ/เฟรมเมนูยังไม่หาย (แก้ที่ CSS + 1 JSX)
- `.drink-card`/`.snack-card` (เซกชันหน้าแรก) — เส้นกรอบ `rgba(...)` → `transparent` (คงมุมโค้ง+เงา+hover เด้ง)
- `.home-card` (การ์ดแนวนอน) — เดียวกัน
- `FoodMenuCard` (/menu การ์ดตั้ง) — ถอด `border border-orange-50` ออกจาก JSX
- **ไม่แตะ** border ของปุ่ม/แท็บ/การ์ดทั่วไป (เฉพาะการ์ดเมนูตามที่สั่ง)

### B3 "ลิงก์เมนูไม่ตรง/ผูกสินค้ายังมั่ว" (แก้ที่ `AdminProducts.tsx`)
**สาเหตุจริง:** ชื่อหมวดใต้การ์ดแอดมินดึงจาก `getCategories()` (ของลูกค้า = เฉพาะ is_active) แต่แท็บ/ตัวกรอง
ดึงจาก `getCategoriesAdmin()` (ทั้งหมด) → หมวดปิด/ไม่ตรง scope ทำให้ชื่อว่าง/ผิด = "มั่ว"
**แก้แล้ว:** อ่าน label จาก `adminCats` (แหล่งเดียวกับแท็บ) fallback `categories` → การ์ดตรงกับแท็บเสมอ

### B4 แถบสถานะเปิดรับออเดอร์ผิด (แก้ = สองเลน)
**กติกาใหม่ตามคำสั่งท่าน (mirror display · server ยังตัดสินตอนสั่งจริง):**
- **เลนเซมเดย์:** "ไม่มีคัทออฟ (สั่งได้ถึงปิดร้าน) · เวลาส่ง · เหลือที่นั่ง" — สั่งได้ตลอดเวลา (148) เหมือนเดิม
- **เลนพรีออเดอร์ (ใหม่):** คำนวณจากรอบจริง + คัทออฟแอดมิน (`pre_order_cutoff` หรือ เวลาส่ง − `cutoff_hours`):
  - รอบวันนี้เลยคัทออฟแล้ว → โชว์ **รอบถัดไปในอนาคต** "📅 พรีออเดอร์: เปิดรับรอบ X (คัทออฟ HH:MM)"
  - ทุกรอบเลยคัทออฟ/ไม่มีรอบต่อ → "📅 พรีออเดอร์: ปิดรับแล้ว — ยังไม่เปิดรอบถัดไป"
  - เซมเดย์ยังเปิดเสมอ (ไม่โดนคัทออฟพรีออเดอร์บัง)
**โค้ด:** `homeProviders.getStoreStatusFromRounds` (+`preOrderLine`) · `StoreStatusStrip` โชว์บรรทัดที่ 3 ·
`types.StoreStatus.preOrderLine` · **เทสต์ใหม่ 2 เคส** (เลยคัทออฟ→ชี้รอบอนาคต · หมดทุกรอบ→ปิดรับแล้ว)
+ เทสต์เดิมทั้งหมด (mascotClosed 18) ยังเขียว = ไม่เปลี่ยนสัญญาเดิม
