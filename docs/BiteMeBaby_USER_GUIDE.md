# User Guide — คู่มือการใช้งานระบบ Bite Me Baby

## ภาพรวม
คู่มือนี้อธิบายวิธีการใช้งานแอปพลิเคชัน Bite Me Baby สำหรับลูกค้า ผู้ดูแลระบบ และผู้ใช้ทั่วไป

## คู่มือสำหรับลูกค้า (Customer)

### การเริ่มต้นใช้งาน
1. เปิดแอปในเบราว์เซอร์ หรือติดตั้ง PWA บนมือถือ
2. ดูเมนูหรือค้นหาอาหารที่ต้องการ
3. เพิ่มสินค้าลงตะกร้า
4. Proceed ไปหน้า Checkout
5. เลือกรอบการส่งและวิธีการชำระเงิน
6. ยืนยันคำสั่งซื้อและรับ order number
7. ติดตามสถานะออเดอร์แบบ real-time

### การนำทางหลัก (Main Navigation)

| ไอคอน | หน้า | คำอธิบาย |
|--------|------|-------------|
| 🏠 | หน้าแรก | Home page พร้อมรายการเด่นและโปรโมชั่น |
| 🍽️ | เมนู | หน้าเมนูพร้อมหมวดหมู่และค้นหา |
| 🛒 | ตะกร้า | Shopping cart พร้อมตัวเลือก checkout |
| 🗣️ | ไบต์ | ผู้ช่วย AI แชท |
| 👤 | โปรไฟล์ | ประวัติส่วนตัวและประวัติสั่งซื้อ (ต้องล็อกอิน) |

### หน้าเมนู (Menu Page)
- Browse by category (จานเดียว, แกง, ข้าว, เครื่องดื่ม, ของหวาน)
- ค้นหา by name
- ดูรายละเอียดสินค้า (ราคา, rating, prep time)
- เพิ่มลงตะกร้าพร้อม customization
- อ่านรีวิว
- 🆕 การ์ดเมนูสไตล์ 3D Floating — ภาพอาหารลอยเหลื่อมขอบบนการ์ด ลอยสูง/ขยายเมื่อชี้หรือแตะ
- 🆕 ปุ่ม "สั่งเลยวันนี้" (Same-day Order) — แสดงเฉพาะเมนูที่พร้อมขายวันนี้ (`is_available = true` ผ่าน Live Availability Engine)
- 🆕 ปุ่ม "จองล่วงหน้า" (Pre-order) — เลือกรอบการผลิต/จัดส่ง (เช้า/กลางวัน/เย็น หรือรอบอนาคต)
- 🆕 สองปุ่มทำงานอิสระต่อกันและบันทึกประวัติ (log) แยกกัน

### ขั้นตอน Checkout
1. **เลือกรอบจัดส่ง**: Morning (6:00-9:00), Midday (11:00-14:00), Evening (17:00-20:00)
2. **ใส่ที่อยู่จัดส่ง**: ต้องอยู่ในรัศมี 5 กม.
3. **เลือกวิธีชำระเงิน**: PromptPay QR หรือ Cash on Delivery
4. **ตรวจสอบคำสั่งซื้อ**: สินค้า, ส่วนลด, ค่าจัดส่ง, ยอดรวม
5. **ยืนยันคำสั่งซื้อ**: รับ order number (รูปแบบ: BM-YYYYMMDD-XXX)

### การติดตามออเดอร์ (Order Tracking)
- ไปที่ `/track/:orderNumber`
- ดูสถานะแบบ real-time: pending → confirmed → preparing → dispatched → in_transit → delivered

### ผู้ช่วย AI (Bite)
- ปุ่มแชทลอยอยู่ที่ทุกหน้า
- ถามเกี่ยวกับเมนู การจัดส่ง โปรโมชั่น
- Quick action buttons: สั่งอาหาร, ติดตามออเดอร์, ถามไบต์
- แชทเต็มจอได้ที่ `/ai-chat` (ต้องล็อกอิน)

### โปรโมชั่นและความภักดี (Promotions & Loyalty)
- ดูโปรโมชั่นบนหน้าแรกและหน้าเฉพาะ
- ใช้คูปองโค้ดในตะกร้า
- สะสม loyalty points ทุกครั้งที่สั่ง
- แลกแต้มเป็น rewards

### คุณลักษณะของผู้ดูแลระบบ

#### Dashboard
- ออเดอร์วันนี้และรายได้
- จำนวนออเดอร์ที่รอดำเนินการ
- อัตราความสำเร็จ
- การแจ้งเตือนสต็อกต่ำ

#### การจัดการสินค้า (Products Management)
- เพิ่ม/แก้ไข/ลบสินค้า
- จัดการหมวดหมู่
- ตั้งค่า availability และ featured status
- ตั้งค่าเวลาเตรียมและราคา

#### การจัดการออเดอร์ (Orders Management)
- ดูออเดอร์ทั้งหมด
- อัปเดตสถานะออเดอร์
- ติดตามการขนส่ง
- ดูรายละเอียดคำสั่งซื้อ

#### การจัดการคลังสินค้า (Inventory Management)
- เพิ่ม/แก้ไข/ลบวัตถุดิบ
- ติดตามระดับสต็อก
- ตั้งค่าการแจ้งเตือนสต็อกต่ำ
- ดูข้อมูลผู้จัดจำหน่าย

## การแก้ไขปัญหา (Troubleshooting)

### ปัญหาการล็อกอิน
- ตรวจสอบอีเมล/รหัสผ่าน
- สมัครสมาชิกใหม่หากจำเป็น
- ล้าง cache หากยังเกิดปัญหา

### ปัญหาเกี่ยวกับคำสั่งซื้อ
- ตรวจสอบ field ที่จำเป็นทั้งหมด (ที่อยู่จัดส่ง)
- ตรวจสอบว่าตะกร้าไม่ว่าง
- ตรวจสอบว่าอยู่ในรัศมีการจัดส่งหรือไม่

### ปัญหา AI Chat
- เช็กการเชื่อมต่ออินเทอร์เน็ต
- Refresh หน้าหากไม่ตอบสนอง
- ใช้แชทเต็มจอที่ `/ai-chat` สำหรับบทสนทนาที่ยาวขึ้น

## เคล็ดลับการใช้
- ใช้สุ่มเมนูเมื่อตัดสินใจไม่ได้
- โหวตเมนูใหม่ๆ ที่เสนอ
- แบ่งปันกับเพื่อนเพื่อรับ referral reward
- เช็กลow stock alerts สำหรับวัตถุดิบสดใหม่
- ใช้ AI สำหรับการแนะนำเมนู
